# Contributing to csl-sqlite

## Reporting issues

Use the GitHub Issue Templates (`.github/ISSUE_TEMPLATE/`) — choose `bug`, `feature`, or `question`.

For **dictionary text corrections** (wrong transcription, markup error), file the issue
on the relevant dictionary repo (e.g., [MWS](https://github.com/sanskrit-lexicon/MWS),
[PWG](https://github.com/sanskrit-lexicon/PWG)), not here.

## Development workflow

1. Fork the repository and create a feature branch.
2. Make your changes; add or update tests where applicable.
3. Submit a pull request with a clear description of the change and its motivation.

## Issue label taxonomy

| Label | Use when |
|---|---|
| `bug` | Incorrect SQLite output or observed behaviour differs from documented behaviour |
| `enhancement` | New capability request |
| `documentation` | Docs are missing or wrong |
| `question` | Clarification needed before filing a bug or feature |
| `minor` / `medium` / `hard` | Estimated effort |
