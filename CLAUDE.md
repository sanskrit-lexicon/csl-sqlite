## Project Overview

**csl-sqlite** is a distribution repository for the SQLite databases of the Cologne Digital Sanskrit Lexicons (CDSL). It provides the latest compiled dictionaries as GitHub Releases assets, allowing users and downstream scripts to download current data without cloning the full pipeline.

**Do not `git pull` this repository.** The Releases assets are large binary files stored via Git LFS or GitHub Releases attachments; a plain pull would fetch excessive data unnecessarily.

## Usage

To get the latest SQLite files:
1. Go to the [latest release](https://github.com/sanskrit-lexicon/csl-sqlite/releases/latest)
2. Download the specific dictionary SQLite file(s) you need

Or use the GitHub CLI:
```bash
gh release download --repo sanskrit-lexicon/csl-sqlite --pattern "<dict>.sqlite"
```

## Architecture

The SQLite files are generated by the CDSL build pipeline (`csl-pywork`) from the digitized source text in `csl-orig`. Each dictionary produces a `<dict>.sqlite` with two primary tables:
- `dict` — one row per dictionary entry, keyed by headword (`key`)
- `flatdict` — flattened full-text index for search

The release cycle: when `csl-orig` source is corrected and the pipeline reruns, updated SQLite files are uploaded as a new release here.

## Dependencies

This repo has no scripts — it is a distribution channel only. The generation pipeline lives in `csl-pywork`.
